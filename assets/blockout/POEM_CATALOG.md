# Модели для болванки «Ноябрь, Москва»

Скачаны официально со Sketchfab (downloadable GLB), меши упрощены
(`max_faces` 2k–12k), нормализованы (pivot `base_center`, метры) и
зарегистрированы в этой библиотеке.

| id | категория | роль в стихотворении | описание |
|---|---|---|---|
| `lp_boy` | character | футболисты / убегающий школьник | Low Poly Little Boy |
| `cartoon_kids` | character | компания во дворе | Cartoon kids |
| `male_casual` | character | дворник, Платонов, Хемингуэй, Моруа | Male in casual clothing |
| `lp_people_pack` | character | запасные фигуры | Lowpoly People pack |
| `soccer_ball` | prop | мяч в окно | Soccer Ball |
| `football_set` | prop | ворота | Football set |
| `old_shovel` | prop | лопата дворника | Old Shovel |
| `soviet_building` | building | московский двор | Soviet Residential Building 2 |
| `wooden_windows` | prop | разбитое окно | Old painted wooden windows |
| `wooden_door` | prop | подъезд | Wooden door |
| `snow_pile` | nature | сугробы | Dirt and Snow Pile |
| `coconut_palm` | nature | Куба | Coconut Palm |
| `palm_trees` | nature | Куба | Palm Trees |
| `eiffel_lp` | building | Париж | Eiffel Tower Low Poly |
| `paris_building` | building | крыши Монмартра | Parisian building diorama |

У каждой записи есть `meta.json` и `description.txt`.
